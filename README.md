# Prumo — downloads

Este repositório publica apenas instaladores do Prumo para pilotos convidados. O código-fonte e os dados dos clientes não ficam aqui.

A edição de avaliação Windows oferece 15 dias de acesso a produtos, movimentações, histórico, relatórios, equipe e cópias de segurança. A emissão de notas fiscais está indisponível. A TechTogs pode prorrogar o prazo com um código temporário.

Baixe somente os arquivos da seção **Releases**. Confira o SHA-256 informado na versão antes de instalar. O instalador do piloto ainda não possui assinatura digital e o Windows pode apresentar o SmartScreen.

Os dados são armazenados localmente no computador da loja. Configure cópias de segurança durante a avaliação.
